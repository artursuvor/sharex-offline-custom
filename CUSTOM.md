# ShareX Offline Custom

Личная офлайн-версия ShareX для Windows x64.

## Изменения

- Ручной размер кисти и текста до 4096, дополнительные быстрые размеры.
- Кнопка `100%` для непрозрачных кисти и заливки фигур.
- Принудительно отключены загрузчики, обновления, внешние ссылки и загрузка изображений по URL.
- HTTP блокируется до создания соединения; FTP, SFTP, отправка почты и ping также заблокированы.
- Сохранены локальный захват, редактирование, буфер обмена и сохранение файлов.
- Запуск по умолчанию в трее: главное окно создаётся при открытии окна или меню трея, стили редактора — при открытии редактора. Горячие клавиши используют сообщения Windows, без постоянного опроса клавиатуры.
- Запись диагностических логов на диск отключена. Настройки и снимки сохраняются при соответствующих действиях; существующие файлы не удаляются.
- Снимки по умолчанию не включают указатель мыши. При включении указатель рисуется непосредственно на исходном изображении области, без отдельного объекта в интерфейсе захвата.
- `PrintScreen` открывает выделение области. `Ctrl+PrintScreen` также оставлен для выделения области.

## Сборка

Требуются Windows и .NET SDK 10. Загрузка зависимостей при сборке требует интернета; готовое приложение работает офлайн.

```powershell
dotnet restore ShareX/ShareX.csproj -p:Platform=x64
dotnet build ShareX/ShareX.csproj -c Release -p:Platform=x64 --no-restore
dotnet publish ShareX/ShareX.csproj -c Release -p:Platform=x64 -r win-x64 --self-contained true -o artifacts/ShareX-Offline
New-Item -ItemType File -Force artifacts/ShareX-Offline/Portable
```

Запуск: `artifacts/ShareX-Offline/ShareX.exe`. Переносите папку целиком. Файл `Portable` включает хранение настроек рядом с приложением.

После сборки проверка фактических DLL:

```powershell
dotnet run --project tests/OfflineSmoke/OfflineSmoke.csproj -c Release
```

Проверка подтверждает запрет HTTP до соединения, запрет ping и принудительное отключение загрузчиков и обновлений.

## Папка снимков и проверка захвата

В настройках укажите системную папку «Загрузки» как папку скриншотов и очистите шаблоны подпапок для обычных снимков и снимков окон. Пользовательские конфигурации хранятся локально и в Git не публикуются.

После сборки можно проверить фактические конфигурации, назначение `PrintScreen`, отключение курсора и прозрачность системных курсоров:

```powershell
dotnet run --project tests/CaptureSmoke/CaptureSmoke.csproj -c Release -- "<путь к ApplicationConfig.json>" "<папка Загрузки>" "<путь к HotkeysConfig.json>"
```

Проверка читает настройки без изменения файлов и без захвата содержимого экрана.
